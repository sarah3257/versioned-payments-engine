# מנוע תשלומים עם חוקים ניתנים להרחבה

מימוש POC חדש ב־.NET 10 עם GoRules.ZenEngine 2.1.8 אמיתי, ללא mock של מנוע החוקים. הפרויקט נפרד מההדגמות הקודמות בתיקייה. הוא כולל פרסום לאחר סימולציה, מודלים ורכיבים בעלי גרסאות, חישוב לפי חודשים ושכבות, תוצאות מוסברות ורטרו לאירוע בודד.

## הפעלה

```powershell
.\Start.ps1
```

פתחו http://127.0.0.1:5188 ולחצו **טעינת תרחיש דיור לדוגמה**. ההפעלה משתמשת ב־SDK המקומי שב־`.tools` אם הוא קיים, אחרת נדרש SDK של .NET 10 מותקן. שחזור חבילות ראשון דורש גישה ל־NuGet. השרת פועל עד Ctrl+C.

```powershell
.\Test.ps1
```

הבדיקות מפעילות את הספרייה המקורית ואת SQLite בפועל. בדיקות HTTP מפעילות גם את ה־API. קובץ תוצאות נכתב אל `test-results/verification.trx`.

## מסלול עסקי קצר

1. טענו את תרחיש הדוגמה. הפרסום עובר ולידציה וסימולציה לפני קליטתו.
2. עברו ל־**רכיבים ומודלים**. בדקו תבנית, פרמטרים, גרסאות ושיוכי שכבות.
3. עברו ל־**חישוב ורטרו** ולחצו חישוב ושמירה. במצב התחלתי נקי: 3,613.16 לחודש, 7,226.32 לספטמבר ואוקטובר יחד.
4. ב־**היסטוריה וביקורת**, סמנו את ספטמבר כשולם בהדגמה. אוקטובר יכול להישאר Pending.
5. ב־**סימולציה ופרסום**, הכינו תיקון מחירון. הכפתור מגדיל את מחיר המזון ב־200. בדקו: תוספת 245.44 לחודש, לאחר רווח ומס. פרסמו.
6. הפרסום אינו משנה אף תשלום. חזרו לחישוב, הכינו אירוע תיקון והריצו: לספטמבר ייווצרו הפרשים; לאוקטובר ביטול לוגי ותכנון חדש.
7. פתחו את הריצה המקורית בהיסטוריה. היא נשארת עם המחיר וההסבר המקוריים.

כפתורי הדוגמה מאפשרים גם להוסיף רכיב מאותה תבנית ללא קוד, לפרסם מודל עם הסכם חדש, ולהוסיף הגדרת חישוב חירום חדשה בלי להוסיף מטפל C#.

## חלוקת הקוד

| פרויקט | אחריות |
|---|---|
| Rules.Domain | חוזי הגדרות, אירועים, תוצאות, טרנזקציות ו־trace |
| Rules.Application | פרסום, זמן וגרסאות, הרצת שכבות, רטרו והשוואה |
| Rules.Infrastructure | מתאם ZEN, cache של ביטויים וטבלאות, SQLite |
| Rules.Api | HTTP, ממשק עברי ותרחישי דוגמה |
| Rules.Tests | בדיקות עסקיות, בטיחות, מקביליות ו־HTTP |

תנאים, סינון, צבירה ונוסחאות רצים ב־ZEN. הקיבוץ משתמש במתאם משותף של .NET; סכום כל קבוצה והנוסחה מחושבים ב־ZEN. לוגיקה עסקית אינה כתובה ב־controller. הגדרות החישוב נמצאות בקובצי examples/templates נפרדים; DemoData טוען אותן ומרכיב חבילת פרסום דרך אותו מנגנון פרסום.

## גבול השימוש

זהו POC מקומי עם נתונים סינתטיים, לא מערכת תשלומים מוסמכת לייצור. אין סליקה בנקאית או זהויות ארגוניות. האחסון מקומי וקבוע על הדיסק, אך משתמש ב־snapshots מלאים לשמירת היסטוריה ואטומיות; הוא אינו תכנון נפחי ייצור. ממשקי הפרסום מוגבלים למחשב המקומי. אין לחשוף אותם דרך reverse proxy ללא החלפת מנגנון ההרשאות.

תעריפים, שמות ועוגנים בדוגמה אינם נתונים עסקיים מאושרים. מדיניות עיגול ברירת המחדל היא שתי ספרות, AwayFromZero, ברמת שורת מקטע. נדרש אישור עסקי למדיניות זו לפני שימוש אמיתי.
