# פרסום גרסת מודל וסימולציה רטרואקטיבית

החל מ־4.11.2026 הזרימה העסקית נמצאת בלשונית ״פרסום גרסת מודל״. לשונית ההסכמות הוסרה, והפרסום החדש אינו תלוי בהסכמות.

## שימוש

1. בחרו מודל וגרסת בסיס והגדירו שם ותקופת תחולה לגרסה החדשה.
2. שנו את הרכב הרכיבים. כל ההשמות של המודל נכללות אוטומטית; מוצגים מזהה ושם המסגרת ותקופת ההשמה.
3. לחצו סימולציה: המערכת משווה תוצאה חודשית תקפה ושמורה מול התוצאה המוצעת. כאשר אין תוצאה שמורה מצוינת תחזית מחושבת.
4. לחצו בצע: הגרסה החדשה והטרנזקציות החדשות נשמרות אטומית, עם קישור לכל תוצאה קודמת.
5. פתחו ״טרנזקציות חודשיות תקפות והיסטוריית החלפות״. יש לקרוא את התוצאה העדכנית לכל חודש, ולא לסכום את כל גרסאות ההיסטוריה.

דוגמה עצמאית: גרסת בסיס 2, נובמבר–דצמבר 2026, הסרת רכיב רווח 10. בנתוני ההתחלה שש השמות ו־12 חודשי השמה: תוספת 1819.766, הפחתה 1315.372, נטו 504.394. קיימת גם השמה שמתחילה ב־10 בנובמבר, עם חישוב חלקי לחודש.

## שמירה וגרסאות

- MonthlyRevisions מצביעה לריצת חישוב ולגרסה הקודמת של התוצאה. CalculationRuns ו־Header/Details נשמרות גם לתוצאה המקורית וגם לחדשה.
- RetroBatches מתעדת ביצוע ומגדירה איזו גרסת מודל מופעלת לכל ההשמות בתקופת התחולה. חישובים חדשים בתקופה משתמשים בה לפני בחירת הסכמה ישנה.
- נעילת הכותב מתאמת את הפעולה בתוך תהליך יחיד. נדרש DB משותף ותיאום נוסף למימוש מרובה מופעים.
- הסימולציה אינה שומרת. טביעת אצבע כוללת את הטיוטה, ההשמות, הנתונים שנבחרו ותוצאת המקור. שינוי מאז הסימולציה מחייב סימולציה חדשה.
- ביצוע חוזר עם אותו מזהה סימולציה מחזיר את התוצאה המקורית ללא כפילות. כשל לפני COMMIT מבטל גרסה, תוצאות וקישורי החלפה יחד.

## גבולות ה־POC

אין תשלום בנקאי, חוב או קיזוז כספי. הסכומים הם תוצאות חישוב, לא כסף ששולם. התחולה בחודשים מלאים, עד חמש שנים; החישוב נחתך לפי תקופת כל השמה. חלק חודש לפי ימים קלנדריים ותאריך קובע בתחילת החפיפה — הנחות עסקיות לאישור. לפני התחולה התוצאות אינן מתחלפות.

בהפעלה הראשונה נוצרות טרנזקציות לימודיות ליולי–דצמבר 2026. בפריסת Vercel בסיס הנתונים עדיין זמני בכל מופע; ההוכחה הפונקציונלית אינה הוכחה לעמידות הנתונים לאורך זמן. אין הרשאות משתמשים או מנגנון תשלומים אמיתי.

## API

- POST /api/model-publication/simulate — טיוטת PublishModel.
- POST /api/model-publication/execute — Draft ו־PreviewToken.
- GET /api/model-publication/current — התוצאה התקפה לכל השמה וחודש ומספר גרסאות ההיסטוריה.

ה־API הישן להסכמות נשמר לתאימות לבדיקות הקודמות; אינו חלק מזרימת הפרסום החדשה.
