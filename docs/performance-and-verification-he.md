# דוח בדיקות וביצועים 4.11.2026

## בדיקות עסקיות

48 בדיקות אוטומטיות בשלב המדידה: נוסחאות, גרסאות, הסכמות, הפרדה לטבלאות, תשלום ששולם לעומת תכנון, חודש חלקי, תום התחייבות, סוף שנה עסקית, תיקון חוזר, מניעת כפילות, כשל לפני COMMIT, שחזור מקור, שדרוג מבנה DB והפעלה מקבילית. הדוח הסופי מופק ב־test-results ואינו אישור כספי של כל דוגמת Word.

בריצה הארוכה מקביליות 4 לא שיפרה תפוקה. בריצה הקצרה עם Server GC נמדד שיפור, אך נפחים, הגדרות ומצב המכונה שונים ולכן אין להסיק גידול ליניארי. ASP.NET Core משתמש ב־Server GC; כלי המדידה עודכן להפעיל אותה הגדרה. נדרשת בדיקה מבוקרת באותו נפח ועם פרופיל זיכרון לפני קביעת תצורת ייצור.

## שחזור המדידות

מהתיקייה הראשית:

- dotnet run --project tools/EngineBench/EngineBench.csproj -c Release -- 10000 12
- node tools/load/http-load.mjs http://127.0.0.1:5110 100

כלי HTTP מוגבל לכתובת localhost כדי לא ליצור בטעות עומס על אתר משותף. קובצי המדידה המקוריים מצורפים ב־docs/evidence.

## מה עדיין לא הוכח

מיליון השמות × 12 ב־DB, ריבוי שרתים, מבחן ממושך של שעות, עצירת תהליך אמיתית ושחזור מגיבוי, SLO ייצור וסף פי 10 מהצריכה הארגונית. טרנזקציות וכשל מוזרק נבדקו, אך הם אינם תחליף לכל אלה.
