# מנוע חישוב וגרסאות — POC עצמאי ב־C# / ASP.NET Core

מערכת מקומית שמפרסמת הגדרות ללא כתיבת קוד לכל מודל, בוחרת גרסאות לפי תאריך והסכמה, מחשבת שכבות בזיכרון ושומרת תוצאה אחת אטומית בסיום.

**סטטוס:** POC עובד ללמידה ולבדיקת התכנון, לא מוצר תשלומים מאושר לייצור. הנתונים דמיוניים/לימודיים ותת־קבוצה של דוגמת הדיור. אין חיבור ל־SAS.

## הפעלה

```powershell
./Start.ps1
```

פתחי בדפדפן: `http://127.0.0.1:5088`. במחשב הנוכחי הותקן SDK מקומי ב־`../.tools/dotnet` בלי לשנות את התקנות ‎.NET הקיימות. במחשב אחר נדרש SDK ‎.NET 10. בחיבור הראשון נדרש NuGet להורדת התלויות.

SQLite נוצר אוטומטית ב־`src/Payments.Api/data/payments-demo.db`. זה DB יחסי פנימי בקובץ, לא JSON שמשמש כבסיס נתונים. קובץ SQLite ניתן לפתיחה בכלי צפייה מתאים; המסך "מבנה הטבלאות" מציג גם את הסכמה האמיתית מהשרת.

### אחרי הורדה מ־GitHub למחשב אחר

1. להתקין SDK ‎.NET 10 יציב ועדכני (לא רק Runtime). קובץ global.json בוחר SDK ממשפחת 10.0.
2. להיכנס לתיקיית `dotnet-versioned-engine` מתוך המאגר ולהריץ `./Start.ps1` ב־PowerShell, או `dotnet run --project src/Payments.Api/Payments.Api.csproj --no-launch-profile`.
3. נדרשת גישה ל־NuGet בשחזור הראשון, הרשאת כתיבה לתיקיית הנתונים ופורט 5088 פנוי. אם מדיניות PowerShell חוסמת סקריפטים, השתמשו בפקודת dotnet הישירה.
4. כל נתוני ההדגמה נוצרים בקוד DemoSeed בהפעלה הראשונה. לא נדרש לייבא DB, Word או קבצים מהתיקיות האחרות במאגר.
5. הקובץ האישי של ה־DB, לוגים, SDK, bin/obj ותוצאות בדיקה אינם חלק מהמאגר. לכן לא יופיעו הריצות שבוצעו במחשב המקורי, אך הגדרות המודלים ונתוני ההדגמה יהיו זהים.

נבדק מקומית ב־Windows עם SDK 10.0.403. יש להריץ את הבדיקות גם בסביבת הארכיטקט; לא ניתן להבטיח מראש התאמה למדיניות הארגונית או לכל מערכת הפעלה.

## נקודות דיוק מול האפיון

- חמישה סוגי חישוב: אחזקה, כוח אדם, סל, רווח ומס; אין התחייבות שכל 30–40 הסוגים העתידיים ממומשים.
- בקשה מחשבת **חודש אחד**, לפי EventDate ומקדם חודש מפורש. יצירת תחזית אוטומטית עד סוף התחייבות ושמירה אטומית של כמה חודשים טרם מומשו.
- עיגול לשורה: 3 ספרות, AwayFromZero, כהחלטת POC לאישור. אין מעבר ל־double בסכומים.
- נתוני ההדגמה אינם import מלא של Word: שני פריטי אחזקה ומקצוע רופא אחד, מחירי ותוקפי דוגמה וסוג מסגרת טקסטואלי. הדגמה זו נועדה לבחירת גרסאות, לא לאישור סכומי האפיון המלאים.
- רווח בדוגמה הוא 4% קבוע. קיימת גם תמיכה בהסכם דרך API, אך רווח לפי הסכם דורש רכיב עם UseAgreement=true. חבות מס על רווח מופעלת רק כשהוגדרה.
- נבחרה שמירת תוצאות בסיום בלבד בהתאם להחלטת המשתמשת בשיחה; זו התאמה לסעיפים שב־Word מתארים שליפת תוצאות ביניים מ־DB.
- אין התחברות, הרשאות, הצפנת נתונים, API ניהול טיוטות, ביטול פרסום או הכנה לענן. השרת קשור ל־loopback; אין לחשוף לרשת/נתונים אישיים לפני הקשחה.

## הסכמות וסימולציה מרובת חודשים

בלשונית ״הסכמות וסימולציה״ אפשר לבחור מסגרות וטווח חודשים, להשוות גרסה קיימת או טיוטת גרסה חדשה ולראות תוספת, הפחתה ונטו לכל חודש ומסגרת. ניתן לפרסם טיוטה ולרשום הסכמות, אך אין עדכון תשלומים קיימים או קיזוז בפועל. פרטי ההנחות וה־API ב־[מדריך הסכמות והשפעה](docs/impact-and-consents-he.md). נוספה טבלת Placements עם ארבע השמות לימודיות. זו הרחבה מעבר לבקשת החישוב הבודדת, שנותרה חודשית.
